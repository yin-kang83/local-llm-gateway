# 负结果：Prompt 不是契约

> 这不是"理论上应该如此"，而是把这个感知层接进一条真实的确定性财务流水线后，
> **实际观测到的失败**，以及每一层闸门如何把它拦下来。
> 记录日：2026-11-27；模型：`qwen2.5:1.5b`（Q4_K_M），纯 CPU（i5-8250U / 7.9 GB）。

## 0. 背景

被测链路（私有系统，此处只描述结构）：

```text
题面 → 本地模型抽参 → 结构契约（Pydantic + Decimal）
     → 确定性算子（Decimal 计算）→ 看门狗断言 → 哈希链底稿池（只追加）
```

核心假设：**模型只"读"，不"算"；模型输出只算"候选"，不算结论。**

## 1. 五个真实失败（按发生顺序）

| # | 模型行为 | 被哪一层拦住 | 结果 |
|---|---|---|---|
| F1 | 明确要求"只输出 JSON"，模型直接给出会计分录文本（"借：长期股权投资 1100 / 贷：银行存款 1000 / 投资收益 100"） | 严格 JSON 抽取 | `json_extraction_error`（exit 5），不进入下游 |
| F2 | 金额字段输出算术表达式字符串 `"1000 + 3000"` | 结构契约（Pydantic `Decimal` 解析） | 校验失败，Worker 拒收；不给默认值 |
| F3 | 把"被投资方的净利润 / 其他综合收益 / 现金股利"编成了借方 2800、贷方 0 的**不平分录** | 看门狗（借贷平衡断言） | `SystemCollapseException` → 事件 `quarantined`，不写事实/快照 |
| F4 | 题面要求"转回已计提的长投减值"，模型老实地把转回金额抽了出来 | 看门狗（会计红线：长投减值不可转回） | `LegalViolationException` → 事件 `blocked`，拒绝写入底稿池 |
| F5 | 抽错减值金额（99999 万元），算子据此算出账面价值为负 | 看门狗（结构完整性：账面价值不得为负） | `SystemCollapseException` → `quarantined`；事实链 11→11、快照 2→2，**坏数没有进底稿池** |

失败率不是重点——重点是**每一种失败都有确定性的归属**，没有一种会"带着错误继续算下去"。

## 2. 同一个提示词的对比

| 配置 | 观察到的行为 |
|---|---|
| 仅自然语言约束"只输出 JSON" | 会答非所问（直接编分录）、会编造结构、会算错金额 |
| `response_format={"type":"json_object"}`（json_mode） | JSON 形态显著稳定，但**字段语义与数值仍可能错**（F2–F5 依旧出现） |
| json_mode + 严格结构契约 + 算子 + 看门狗 | 上述错误全部在写库前被拦截 |

结论：`json_mode` 只提高"形态合规率"，**不提高语义正确率**。所以提示与校验必须分层，不能互相替代。

## 3. 由此固化的四条设计规则

1. **场景识别用规则，不用小模型**：把"成本法转权益法 / 权益法后续计量 / 减值转回"
   交给确定性关键词路由选短提示词后，一次通过；让一个提示词应付全部场景时，F3 必现。
2. **模型不碰算术**：需要"初始成本 + 追加对价"这类合计时，由确定性代码相加；
   模型只允许输出被加数。F2 就是模型试图做算术的直接证据。
3. **fail-closed，不给默认值**：抽不出、解析不了、结构不合法 → 抛错；
   空补全不补 `{}`，超时不用上次结果，JSON 失败不做"正则硬抠"。
4. **看门狗必须在写库之前**：F3/F4/F5 的共同点是"坏输入"与"坏结果"；
   只要断言在 `commit` 之前，底稿池就只会包含通过断言的事实与快照。

## 4. 与该负结果对应的离线测试

本仓库不包含上面那条私有流水线，但契约行为有离线测试覆盖（51 项，无网络）：

- JSON 抽取严格性：非 JSON、半截 JSON、prose 包裹（默认拒绝）；
- 结构契约：超预算、空补全、协议不合规一律抛类型化错误；
- 证据与密钥：失败也会留下哈希级审计线索，且不泄漏 API Key；
- 失败语义：错误码与 CLI 退出码稳定（2/3/4/5），调用方可分支处理。

## 5. 论文可用的一句话表述

> 在将本地 1.5B 级模型接入确定性财务流水线的实测中，模型在五次可复现的失败里分别表现出
> 指令违背、结构伪造、算术错误与语义误读；这些失败均被"结构契约 + 确定性算子 + 写前断言"
> 三层闸门拦截，未产生任何被污染的事实或快照。这表明 —— **Prompt 不是契约，模型的合规性
> 不能由提示词保证，只能由下游的确定性约束保证。**
